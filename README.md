# academic-perfromance-tracker
#This project was created for the tedious work of teachers with various grades from different classes for different students. The program knocks out the busywork (student scores, final grade calculation, letter grade calculation, and Academic standing)

Built in Python for MIS 120 at Sacramento State (Spring 2026).

## What it can do

- **Add/Remove Students** from the three different sections.  Move a student from one section to another.
- **Grade automatically:** score averages are calculated up as weighted grades and letter grades. Students are noted as being in Good Standing or on Academic Probation.
- **Compare sections** to see which class is doing best
- **Export reports** as text, CSV, or JSON files
- **Save everything automatically** to a database, so nothing is lost when you close it.

## Built with

Python · SQLite · SQL · JSON

## Try it

You only need Python 3. Download the files, then run: `` `python performance_tracker.py` ```

```
python performance_tracker.py
```

It includes six sample students to test the system out right from the start – all students are fictional.
